# Plugin Blockbench

À faire. Blockbench, l'outil de modèles 3D des moddeurs, accepte des plugins en JavaScript.

Piste : montrer un système Sparkle sur un modèle (une torche, une arme...) pour le régler en contexte. La simulation
et l'aperçu de l'extension VS Code (`../vscode/src/shared`) sont en TypeScript et peuvent être réutilisés.
