# Plugin MCreator

À faire. MCreator accepte des plugins (`.zip`) qui ajoutent des éléments de mod, des procédures (blocs Blockly) et
des générateurs de code pour chaque loader.

Piste : un élément « Système de particules Sparkle » et des procédures « jouer / arrêter un système », générés avec
le runtime Sparkle. C'est le plus difficile : l'éditeur visuel devrait être refait dans l'interface Java Swing de
MCreator.
