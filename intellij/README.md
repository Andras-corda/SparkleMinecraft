# Plugin IntelliJ IDEA

À faire. L'IDE le plus utilisé pour les mods Java (Minecraft Development, Forge, NeoForge, Fabric).

Piste : un plugin Kotlin (IntelliJ Platform Gradle Plugin) qui reprend Sparkle :
- l'éditeur dans une vue JCEF, où l'interface web de l'extension VS Code peut resservir ;
- l'installation du même runtime Java (`../vscode/runtime`).
